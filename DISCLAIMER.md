# Disclaimer

**This project is an educational and research-only prototype. It is not a diagnostic device.**

Do not use this software to screen, diagnose, treat, or rule out cancer or any other medical condition. Model scores are demonstration outputs from a binary EfficientNet-B0 classifier. They are not clinical findings.

The bundled checkpoint is trained on **synthetic images** so the interface and Grad-CAM pipeline can be exercised. It has not been validated on real medical data, has no regulatory clearance, and must not be deployed for patient care.

Always consult a licensed clinician for medical decisions.
